Appearance, Colours, and Fonts Preferences


Appearance

启用主题
If selected, themes are enabled or disabled. A restart will be required for this change to take effect.

Theme
选择要用于Archi的主题。此更改需要重新启动才能完全生效。

If the theme is set to "Automatically select Light/Dark" the theme will be set according to the current operating system theme of light or dark when starting Archi. Some system dark themes are not supported and so this setting might not work. If this is the case, select another theme to suit the host system theme.

使用圆形标签页
Whether to use round or square tabs.

Show Status Bar
显示或隐藏状态栏。此更改需要重新启动才能生效。

Use larger (Mac native) row heights
When this is selected, all table and tree row heights are larger to match the UI in macOS 11 and later. A restart will be required for this change to take effect.


颜色

Choose the default colours to use for elements, connections, folders and some theme colours.

Element and connection colours will be displayed when a fill or line colour is set to "Default" in the Properties window for a diagram element or connection.可以为每个Archi安装设置不同的默认颜色，因此，例如，一个用户可以具有与另一个用户完全不同的默认填充颜色集。颜色将不会保存在中。存档模型文件，除非勾选“在.archimate文件中保存新概念的默认填充颜色”选项。

Folder colours are local to the application and are not saved in the model.

Theme colours for backgrounds can be set for each theme as set in the Appearance preference. These are for the application and are not saved in the model.

用户设置的颜色会在标签后显示星号。右键单击树以选择“全部展开”或“全部折叠”。

Derive element line colours from fill colours
If this is checked a newly created diagram object's line colour is derived from its fill colour. The setting for each object can be changed in the object's properties tab.

保存模型文件中元素的默认填充颜色
If this is checked an element's default colour is saved in the model file and will then be "fixed" in the file. This ensures that if the file is shared with another user they will see these colours.

Fonts

Scale fonts for diagram objects and connections on Mac
此选项仅在Mac上可用。选择此选项后，将调整图表（视图）对象和连接中使用的字体，以匹配Mac上的本机DPI （每英寸点数）。这可确保在Mac、Windows和Linux之间共享模型时，字体看起来大小相同。

For example, you might work on an Archi model on Windows and set the font height for an object to 10. However, when opening the model on Mac the font will appear too small because Mac uses 72 DPI while Windows uses 96 DPI. Conversely, you might set the font height on Mac but it appears too big on Windows. This setting adjusts for this difference so that font heights appear the same on all platforms.

注意-如果当前默认字体是内置默认字体，选择此选项会自动将字体从“Lucida Grande 12”切换到“Lucida Grande 9” ，反之亦然，以补偿新的缩放。


Set fonts for these items
Set the default font for elements and connections in diagrams (Views) and fonts for various user interface controls. Clicking the "Default" button sets the default font for the selected items. The "Edit" button will allow you to set the font for the selected items.
