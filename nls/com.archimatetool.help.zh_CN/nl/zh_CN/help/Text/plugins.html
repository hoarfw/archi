Managing Plug-ins

您可以使用Archi插件管理器或手动安装和卸载Archi插件。

Using the Plug-ins Manager

To install or uninstall an Archi plug-in, select "Manage Plug-ins..." from the Help menu.

将显示Archi插件管理器对话框。在这里，您可以查看已安装的插件及其详细信息。

Installing

To install an Archi plug-in using this method you need to have the plug-in in Archi plug-in format. This is an archive file (*.archiplugin or *.zip file extension) containing one or more jar files and a marker file.此类Archi插件的示例包括Collaboration和jArchi Scripting插件。如果插件是JAR文件，则需要手动安装（见下文）。

To install a new plug-in, click the "Install..." button. Select the plug-in file or files that you wish to install. You can select and install more than one plug-in if you wish. You will be prompted to restart Archi.

Uninstalling

已安装的插件将显示在对话框的表视图中。如果您想安装一个或多个插件，请选择它们并单击“卸载”按钮。系统将提示您重新启动Archi。


Manual installation

If the plug-in is in *.jar file format you can simply copy the *.jar file(s) to Archi's special "dropins" directory. (Ensure you quit Archi first before doing this.)

“dropins”目录位于以下位置：

Windows: user.home/AppData/Roaming/Archi/dropins

Mac: user.home/Library/Application Support/Archi/dropins

Linux ： user.home/.archi/dropins

("user.home" denotes your home directory.)

If the "dropins" directory does not exist, you will need to create it first.
